# Magic Board — iPad Web App

This is a no-Mac version of the Magic Board.

## Features
- Full-screen handwriting canvas.
- Apple Pencil and touch support.
- Clear & Save automatically stores a PNG snapshot before clearing.
- Archive with thumbnails and full-screen viewer.
- Delete saved boards.
- Local storage: data stays in the browser on the device.
- PWA files included for Add to Home Screen.

## Important
For the cleanest iPad experience, host these files on a static HTTPS site. Then open the site in Safari and use:
Share → Add to Home Screen.

No account or server database is required for saved boards.

## Quick hosting options
Upload the folder to a static host such as GitHub Pages, Netlify, Vercel, or Cloudflare Pages. The files do not require a backend.
